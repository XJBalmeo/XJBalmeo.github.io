## Concept & Vision

The portfolio is themed as **XEON_OS** — an operating system / cyberpunk city hybrid. Instead of a traditional scroll-based portfolio, the user:

1. Lands on a **live 3D city** (`CityScene`) viewed from an isometric camera.
2. Sees **5 interactive buildings** floating in the city grid, one for each portfolio section (About, Education, Skills, Projects, Contact).
3. Clicks a building → **camera zooms in** via smooth lerp → transitions to the **Building Interior** (`BuildingInterior`).
4. Inside, a draggable **3D office room** renders with holographic pedestals. Clicking a pedestal opens a **Persona-style dual-tone modal** with the actual content.
5. A "Back to City" button transitions back out.

Design palette: `deep navy (#0a0e1a)` + `sky cyan (#38bdf8)` + glowing glass materials.

### `src/` — Core Source

#### `src/main.jsx`
React entry point. Calls `createRoot(document.getElementById('root'))` and renders `<App />` inside `<StrictMode>`. Imports `index.css`.

#### `src/App.jsx`
**The master router/state.** Holds a single piece of state: `activeBuilding` (null or a building ID string like `'about'`).

- `activeBuilding === null` → renders `<CityScene>`
- `activeBuilding !== null` → renders `<BuildingInterior buildingId={...}>`
- `<AnimatePresence mode="wait">` handles the fade transition between the two worlds
- `<LoadingScreen />` is **always mounted** — auto-dismisses after R3F finishes loading

#### `src/index.css`
Global design system. Key parts:
- **Google Fonts**: `Geist` (body), `Outfit` (headings), `JetBrains Mono` (mono/code)
- **Tailwind `@theme`**: Custom CSS tokens (`--color-night-sky`, `--color-accent: #38bdf8`, `--color-window-glow`, etc.)
- **Keyframes**: `twinkle`, `driveRight`, `driveLeft`, `windowToggle`

---

### `src/components/` — Components

#### `CityScene.jsx` ★
The most complex file (1036 lines). The **outdoor 3D world**. Contains many sub-components defined in the same file:

| Sub-component | What it does |
|---|---|
| `CyberSky` | Procedural sky sphere via `lamina` (Color + Depth + Noise layers). Deep navy gradient. |
| `createWindowGroup()` | Factory: creates a Canvas2D texture of animated glowing windows. Returns `{ texture, update }`. 6 instances pre-created. |
| `createAsphaltTexture()` | Canvas2D noise texture for road/ground surface. |
| `AnimatedWindows` | Invisible `useFrame` component that calls `update()` on all 6 window textures every frame. |
| `Streetlights` | Hundreds of lamp post meshes along the road grid, computed with `useMemo`. |
| `InteractiveBuilding` | One of the 5 clickable portfolio buildings. Uses CSG (`<Geometry>`, `<Base>`, `<Subtraction>`, `<Addition>`) to carve unique shapes per `data.type`. Uses `meshPhysicalMaterial` + `<Edges>` for the glowing wireframe look. Hover float animation via `useFrame` + `THREE.MathUtils.damp`. |
| `BuildingMesh` | Generic ambient background building. Multi-material `meshStandardMaterial` with window texture as `map` + `emissiveMap`. |
| `AmbientCityGrid` | Procedurally generates: ground plane (`<RigidBody type="fixed">`), sidewalks, road segments with lane dividers + edge glow lines, intersection yellow X markings, all ambient buildings. |
| `Car` | Animated car on a road lane, checks `globalTrafficState` to stop at red lights. Wraps at ±60 units. |
| `Traffic` | Spawns 35 cars. Manages `globalTrafficState.zGreen` timer (toggles every 4 seconds). |
| `Pedestrian` | Capsule mesh that walks along sidewalks with a bob animation. |
| `Pedestrians` | Spawns 60 pedestrians. |
| `TrafficLights` | Traffic light poles at intersections, reads from `globalTrafficState.zGreen`. |
| `MovingClouds` | 20 transparent sphere clusters drifting slowly across the sky. |
| `CameraRig` | Controls camera via `useFrame`. Idle: follows mouse with damping. When `targetBuilding` set: lerps toward it, fires `onZoomComplete` when close. |
| `Hovercars` | 20 glowing sphere "hovercars" flying at high altitude across the city. |
| `BackgroundCity` | 350 distant buildings (radius 50–140 units) with CSG corner cuts. `meshBasicMaterial` for performance. |

The exported `CityScene` assembles everything inside a `<Canvas>`:
- `EffectComposer` with Bloom + Chromatic Aberration + Noise
- `<Stars>` from drei, fog
- `<Physics>` wrapping city grid + traffic
- A floating glassmorphism **taskbar** rendered as HTML overlay (outside Canvas)

#### `BuildingInterior.jsx` ★
The **inner 3D world** (322 lines). Receives `buildingId` and looks up content from `CONTENT_MAP` at the top of the file.

`CONTENT_MAP` — 5 keys (`about`, `education`, `skills`, `projects`, `contact`), each with:
- `id`, `title`, `statLabel`, `statValue`
- `items[]`: array of `{ id, badge, title, desc, position }` — one per 3D pedestal

Sub-components:
- `Pedestal`: A 3D workstation — dark slate base mesh, monitor screen mesh, floating `<Float>` glass sphere (the click target), `<Text>` label. Clicking calls `setActiveToast(data)`.
- `Room`: Office room — floor plane, 10 holographic data server arrays, back wall, EXIT door with `<Text>`, scene lighting, `<Environment preset="city">`.

The exported `BuildingInterior`:
- Full-screen `<Canvas>` with `<PresentationControls>` (drag-to-rotate, spring physics)
- **XEON_OS logo** (animated geometric diamond + text) top-left HTML overlay
- "Back to City" button top-right
- `<AnimatePresence>` for the **dual-tone modal** when `activeToast !== null`

#### `LoadingScreen.jsx`
Uses `useProgress` from drei (0–100). Fades out 1.2s after `progress === 100`. Shows: "Xeon" title, "WEB PORTFOLIO" subtitle, glowing yellow progress bar, percentage counter.

#### `ScrollReveal.jsx`
Utility wrapper. Applies Framer Motion `whileInView`: `opacity 0→1`, `y 24→0`, `filter blur(8px)→0`. Respects `useReducedMotion`. **Named export** — `export function ScrollReveal`.

#### `AmbientCity.jsx` — LEGACY / DORMANT
Pure CSS parallax: 15 dark rectangle buildings at screen bottom. Uses `useScroll` + `useTransform`. Not used in `App.jsx`.

#### `NightSky.jsx` — LEGACY / DORMANT
CSS star field (50 white divs with `twinkle` animation) + moon div. Not used in `App.jsx`. Pre-3D version remnant.

#### `Elevator.jsx` — LEGACY / DORMANT
Fixed left sidebar with 5 floor buttons. Reads `scrollYProgress` to determine active floor. Was used when the portfolio was a vertical-scroll page. Not used in `App.jsx`.

## The Two-World System

Two completely separate `<Canvas>` instances — one in `CityScene`, one in `BuildingInterior`. Never mounted simultaneously (`AnimatePresence` swaps them). Each world fully owns its WebGL context.

**State bridge:** `activeBuilding` in `App.jsx` is the sole connector. `CityScene` calls `onEnter(id)` when the zoom animation completes. `BuildingInterior` calls `onExit()` to return.

## 3D Scene Internals — CityScene

### City Grid Constants
```js
ROAD_WIDTH = 3.0   // units
BLOCK_SIZE = 5.0   // units
SPACING    = 8.0   // ROAD_WIDTH + BLOCK_SIZE
```
Grid generated for range `-4 to +4` on both X and Z axes.

### Building Architecture (CSG)
Each of the 5 interactive buildings has a `type` determining what boolean operations are applied:

| Type | Building | CSG Operations |
|---|---|---|
| `tower` | ABOUT | Slanted roof cut + mid-section tunnel cutout |
| `block` | EDUCATION | Pyramid roof addition + front/back colonnade subtractions |
| `antenna` | SKILLS | Two diagonal corner cuts (cross shape) + spherical hole near top |
| `tiered` | PROJECTS | Left/right/front step cuts for tiered silhouette |
| `pavilion` | CONTACT | Cross hollow cuts (phone booth) + cylindrical roof addition + sign |

All 5 use `meshPhysicalMaterial` (`transmission: 0.8`, glass-like) + `<Edges>` (wireframe highlight).

### Performance Notes
- **Window textures**: 6 Canvas2D textures updated in batch by `AnimatedWindows` each frame
- **Background city**: 350 buildings use `meshBasicMaterial` (no lighting calculations)
- **Distant buildings**: CSG used but `castShadow={false}` / `receiveShadow={false}`
- **Physics**: Only the ground plane has a `<RigidBody>`. Cars/pedestrians are kinematic (pure `useFrame`)

## Interior World Internals — BuildingInterior

### CONTENT_MAP
Located at the top of `BuildingInterior.jsx`. A plain JS object keyed by building ID.

**⚠ This is the primary place to update all personal data.** Current state: mix of real data and placeholders.

### Modal System
`activeToast` state holds the clicked `item`. `<AnimatePresence>` shows/hides. Entry uses spring physics (`stiffness: 300, damping: 30`). Close: button sets `setActiveToast(null)`. Backdrop click dismiss not yet implemented.

## Known Gaps / Next Steps

From `handoff.md` and code analysis:

1. **`CONTENT_MAP` needs real data** — Placeholder text in `BuildingInterior.jsx`. Real data lives in `src/sections/`. These two need to be synced.

2. **`src/sections/` are orphaned** — Not rendered anywhere. Decide: extract data into `CONTENT_MAP`, or re-integrate as HTML content inside the interior world.

3. **Dead legacy components** — `AmbientCity.jsx`, `NightSky.jsx`, `Elevator.jsx` are unused. Candidates for removal or archiving.

4. **`src/hooks/` is empty** — Reserved for custom hooks (e.g., `useAudio`, `useThreeScene`).

5. **Mobile optimization** — `PresentationControls` touch gestures emit `@use-gesture` warnings. Taskbar + modal need responsive testing at mobile breakpoints.

6. **No contact form backend** — `ContactFloor.jsx` has `onSubmit={(e) => e.preventDefault()}`. Needs real integration (Resend API, EmailJS, Formspree, etc.).

7. **Sound design** — Optional. Audio tick/click cues for terminal interactions would fit the OS theme perfectly.

8. **`leva` debug panel** — In dependencies but not actively used. Can be wired to tune bloom intensity, fog density, building colors live during development.
