# UI Reverse Engineering Skill

This skill provides you with the capability to reverse engineer any website or design reference and translate it into a structured Markdown specification.

## Instructions for the Agent

When the user requests to use this skill or reverse engineer a website:

1. **Analyze the Design**: Evaluate the website's structure, color palette, typography, spacing, layout, and interactive elements. If a URL is provided, you can use browser subagents to view it, or if an image is provided, use vision.
2. **Document the Design System**: Produce a markdown file (e.g., `ui-spec.md`) containing a detailed breakdown of the design system.
3. **Specify Components**: Include specific CSS styles, layout structures (e.g., flexbox/grid), hover states, micro-animations, and 3D integration patterns if applicable.
4. **Actionable Implementation**: Provide actionable instructions for how to replicate this design in the current project (using Tailwind, vanilla CSS, React, Framer Motion, etc.).
5. **Premium Aesthetics**: Ensure the translated spec emphasizes creating a pixel-perfect, high-end, dynamic look that wows the user.
